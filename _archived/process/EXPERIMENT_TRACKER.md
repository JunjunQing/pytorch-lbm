## RESOLUTION (2026-08-06) ✅ R*=2.76 MYSTERY SOLVED

**Question**: why is k bit-identical across amp=0.2-1.5 (R027-R035) at R*=2.76?

**Root cause — design artifact, not physics** (scripts/resolve_r276.py, 5 deconfounded
runs on grid 150x150x146, N=3000):

| label | amp | theta | max_k | Dx/Dy | err vs Liu 1.33 |
|-------|-----|-------|-------|-------|------------------|
| A_amp0_th162 | 0.0 | 162 | 1.3784 | 51/37 | **+3.6% ✓** |
| E_amp0.1_th162 | 0.1 | 162 | 1.6857 | 59/35 | +26.7% ✗ |
| (M4 R027-R035) | 0.2-1.5 | 162 | 1.6857 | 59/35 | +26.7% ✗ |
| B_amp0.5_th140 | 0.5 | 140 | 1.8000 | 63/35 | +35.3% ✗ |
| D_amp0_th140 | 0.0 | 140 | 1.5405 | 57/37 | +15.8% ✗ |
| C_amp0.5_th150 | 0.5 | 150 | 1.8000 | 63/35 | +35.3% ✗ |

**Findings**:
1. `fe_wetting.py:491` amplifies only when `amp > 1.0`; amp in (0, 1.0] all run
   the identical un-amplified code path -> invariance across 0.2-1.0 is
   **constructional**, not physical.
2. `geometric_wetting=(amp > 0)` — amp=0 disables the wetting BC entirely; the
   M4 sweep started at amp=0.2 and **never tested amp=0**, the only distinct
   code path. Case E proves any amp>0 (even 0.1) gives the same 1.6857.
3. The phase4a "solved" value (k=1.308 on grid 150x150x107) is **not** a grid
   artifact: Case A on the M4 grid (nz=146) gives k=1.3784 (+3.6% ✓).
4. **Correct operating point: theta=162, amp=0** at R*=2.76 — consistent with
   the amp vs R* calibration (2.0->1.0, 2.76->0, DEVELOPMENT.md §8.1) and the
   paper's threshold "alpha effective only for R*<3.0".
5. R036 (theta sweep 140-155) is **moot**: low theta does not restore amp
   utility — wetting ON over-shoots at every theta (Dx=59-63 vs 51-57);
   theta=140 even worsens amp=0 (1.5405, +15.8%). theta=162/amp=0 is optimal.

**Conclusion**: close R036 as resolved-by-analysis; recommend amp=0 for
R* >= 2.76 (low curvature needs no geometric amplification).
